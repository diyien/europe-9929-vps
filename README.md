## 9929是条什么线，法兰克福凭什么成欧洲节点首选

法兰克福能成欧洲 9929 的集散地，原因很实在：它是欧洲最大的互联网交换节点之一，DE-CIX 就在那儿，国际带宽充足，联通 9929 在当地有比较稳定的接入资源。机房放在这里，往欧洲各地和中国大陆两头都不吃亏。
